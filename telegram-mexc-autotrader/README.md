# Telegram MEXC Autotrader

Автоматический торговый бот для фьючерсов MEXC (USDT-M), который слушает сигналы из Telegram-канала и исполняет сделки.

## ⚠️ Предупреждение о рисках

**Торговля криптовалютой сопряжена с высоким риском потери средств.** Этот бот — инструмент автоматизации, а не гарантия прибыли. Вы используете его на свой страх и риск.

- Никогда не торгуйте на последние деньги
- Всегда тестируйте в режиме DRY-RUN перед реальной торговлей
- Плечо x25 означает высокую волатильность позиции
- Бот не несёт ответственности за ваши убытки

## 📋 Требования

- Python 3.9+
- Аккаунт Telegram (для USER-клиента)
- API-ключи MEXC с правами на фьючерсы
- Подписка на канал с сигналами (или свой канал)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd telegram-mexc-autotrader
pip install -r requirements.txt
```

### 2. Настройка .env

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

#### Telegram API (my.telegram.org)

1. Зайдите на https://my.telegram.org
2. Войдите по номеру телефона
3. Перейдите в "API development tools"
4. Создайте новое приложение (любые название и описание)
5. Скопируйте `api_id` и `api_hash` в `.env`

```env
API_ID=12345678
API_HASH=abcdef1234567890
PHONE=+79991234567
CHANNEL=crypto_signals_channel  # username без @ или ID вида -100...
```

#### MEXC API

1. Зайдите в аккаунт MEXC
2. Профиль → API Management
3. Create Key
4. **Важно:** включите права **Futures** (чтение + торговля)
5. Скопируйте ключи в `.env`

```env
MEXC_API_KEY=mx_abcdefghijklmnop
MEXC_SECRET=ABCDEFGHIJKLMNOPQRSTUVWXYZ123456
```

### 3. Первый запуск

```bash
python main.py
```

При первом запуске:
1. Скрипт запросит номер телефона и код подтверждения Telegram
2. Созстся сессия `mexc_trader.session`
3. Откроется главное меню

## 📖 Главное меню

```
==================================================
TELEGRAM MEXC AUTOTRADER
==================================================

[1] Запустить торговлю
    Current: Margin: 10.0 USD | Leverage: x25 | Dry-run: True
[2] Изменить маржу
[3] Toggle DRY-RUN
[4] Exit
```

### Пункты меню

- **[1] Запустить торговлю** — старт прослушивания канала и торговли
- **[2] Изменить маржу** — установить размер маржи для новых сделок (сохраняется в `settings.json`)
- **[3] Toggle DRY-RUN** — включить/выключить режим эмуляции (без реальных ордеров)
- **[4] Exit** — выход из программы

## 🎮 Живые команды (во время торговли)

После запуска торговли можно вводить команды без остановки скрипта:

| Команда | Описание |
|---------|----------|
| `margin <значение>` | Изменить маржу для будущих сделок |
| `status` | Показать текущие настройки и активные сделки |
| `help` | Список команд |
| `stop` | Корректная остановка |

Пример:
```
margin 15
# Margin updated to 15.0 USD
```

## 📨 Формат сообщений

Бот парсит два типа сообщений:

### Тип 1: Открытие позиции

```
МАРАФОН СО 100$ by ARKADIY
Открыл GRASS LONG 🔘

Моя маржа 10$ плечо x25

➦ Ссылка на монету
```

**Важно:** Маржа и плечо из сообщения игнорируются! Используется маржа из `settings.json` и фиксированное плечо x25.

### Тип 2: Цели и стоп

```
🔘 GRASS LONG плечо x25

Точка входа: рынок (0.3235)

Таргет 1: 0.3268
Таргет 2: 0.3314
Таргет 3: 0.3457

Стоп: 0.3058

Моя маржа: 10$
Банк марафона: 114.92$

➦ Открыть сделку
```

Поддерживается 1–4 таргета. Последний таргет всегда закрывает остаток позиции после округлений.

## 🔧 Логика торговли

1. **Открытие**: Market-ордер на сумму `margin * 25` (плечо фиксировано)
2. **Ожидание целей**: `TARGETS_TIMEOUT_SEC` (по умолчанию 120 сек)
3. **Установка целей**: Limit-ордера на закрытие (50% / 25% / 25%)
4. **Стоп-лосс**: Trigger market-ордер на весь объём
5. **Менеджмент**: После каждого TP стоп переставляется на остаток
6. **Завершение**: Когда позиция закрыта полностью

## 🔄 Автозапуск (systemd)

Пример сервиса для Linux:

```ini

[Unit]
Description=MEXC Telegram Autotrader
```

## ❓ FAQ

### Бот не подключается к Telegram
Проверьте `API_ID`, `API_HASH`, `PHONE` в `.env`. Убедитесь, что номер в международном формате.

### Ошибка "CHANNEL not found"
Для публичных каналов используйте username без `@`. Для приватных — числовой ID (можно получить через @userinfobot).

### DRY-RUN показывает неверные цены
В режиме эмуляции используются цены из тикера MEXC на момент сигнала. Реальные исполнения могут отличаться.

### Как изменить маржу во время работы?
Используйте команду `margin <значение>` в консоли. Изменение применится к следующим сделкам.

### Бот пропустил сигнал
Проверьте логи `logs/trader.log`. Возможные причины: контракт не найден на MEXC, уже есть открытая позиция по этому тикуру, ошибка API.
